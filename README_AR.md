# Voice Translator — إصدار مطوّر مبدئي

## ما يتضمنه
- واجهة عربية متجاوبة نسبيًا، وضع فاتح/داكن مع حفظ التفضيل.
- 24 لغة للاختيار (توفر الترجمة والتعرف والنطق يختلف حسب المحرك).
- إدخال نص وترجمته، تعرف صوتي عند دعم المنصة، ونطق للترجمة.
- تبديل اللغات ونسخ النص وسجل ترجمات مؤقت خلال الجلسة.

## المتطلبات
Flutter/Dart حديث، Android Studio أو VS Code، جهاز/محاكي Android، واتصال إنترنت للترجمة.

## التشغيل
```bash
flutter doctor
flutter pub get
flutter run
```
للوِب:
```bash
flutter config --enable-web
flutter run -d chrome
```

## حدود النسخة
هذه نسخة مصدر أولية ولم يتم تشغيل Flutter build أو اختبارها في هذه البيئة. الترجمة تستخدم حزمة طرف ثالث غير رسمية وقد تتعطل أو تتغير؛ لا تستخدمها في منتج تجاري دون استبدالها بخدمة موثوقة. سجل المحادثات غير محفوظ بعد إغلاق التطبيق. لا يوجد أوفلاين كامل أو ترجمة ملفات صوت/فيديو أو محادثة تلقائية مستمرة. اختبر اللغات والصوت على كل منصة قبل النشر.
